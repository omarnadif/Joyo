## Dove incollarli

**Play Console** → Presenza sullo store → Scheda dello store principale:
titolo + descrizione breve + descrizione completa. Poi "Aggiungi traduzioni"
per ogni lingua (en-US, es-ES, fr-FR, de-DE).

**App Store Connect** → App → versione 1.0 → per ogni lingua (localizzazioni):
nome + sottotitolo + testo promozionale + descrizione + parole chiave.

Restano da preparare a parte: icona 512×512 (Play), feature graphic 1024×500
(Play), screenshot (min 2 per store; iOS: 6,7" e 6,5" obbligatori).
